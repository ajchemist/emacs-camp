# emacs-camp

The terminal opens a container with [emacs-camp](https://github.com/ajchemist/emacs-camp)
installed: Emacs 31.1 (terminal build), vertico/orderless/consult/embark,
corfu, magit, and the rest of `lisp/init.el`.

Type `emacs` to start it (the first start takes a few seconds). `C-x C-c` quits.

The session lasts an hour and nothing is kept afterwards.
